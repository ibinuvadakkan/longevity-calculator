# Life Expectancy Estimator - Blue Zone Habits Calculator

This is a **web application** that estimates potential lifespan gains based on adopting Blue Zone lifestyle habits. Users can select habits and see how many years they could add to their life.

## Features

- Select multiple longevity habits
- See estimated years gained
- View a detailed breakdown of each habit's contribution
- Fully responsive and mobile-friendly

## Live Demo

Check out the live page: [HealthiWellness Article](https://healthiwellness.com/7-proven-lifestyle-health-habits-for-longevity-that-really-work/)

## Usage

1. Clone this repository
2. Open `index.html` in a browser
3. Interact with the calculator
